# 2026-09-05 工作日志

## 项目体检发现: 日线数据断供 (P0)

对 A 股选股系统做整体体检, 发现一个长期隐蔽且后果严重的缺陷。

**根因链**
1. 之前的"选股提速 32 倍"优化把选股改为只读本地缓存, 缓存维护职责移交后台常驻服务 `data_updater`
2. 但 `data_updater` 的 `_roll_refresh()` 与 `patch_forming_candles()` 只覆盖
   `hourly_kline` / `kline_5min`, **遗漏了 `daily_kline`**
3. 日线缓存冻结在 2026-08-28, 缺口 8/31~9/4 共 5 个交易日
4. 选股器 `fast_combo` 的"日线趋势确认"关卡持续使用陈旧均线,
   但日志正常、命中数正常, 故障完全不可见

**影响**
- 修复前后选股命中名单**零重叠** (9 只 vs 13 只), 此前候选池整体失效
- 实盘持仓决策未受影响 —— 主人日常的 `today_open/pm_check/condition_check/levels_tomorrow`
  都是独立脚本直连新浪 API, 绕开了这个坑
