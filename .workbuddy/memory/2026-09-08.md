## 板块轮动预测：文本数据方法调研（网络搜索结论）

**核心发现：新闻无效，专业文本有效**

| 文本源 | 年化超额 | 来源 |
|---|---|---|
| 通用财经新闻情感 | ≈0（无稳健预测力） | MDPI 2025, 186万条标题; TextBlob/VADER/FinBERT 均无效 |
| 机构调研问答 | 6.84% (IR 0.88) | 中信建投 |
| 分析师研报情感因子 | 9.1%（多空12.2%, 盈亏比1.84） | 中金 |
| **基金季报"市场展望"文本** | **14.37%（年化16.23%, 季度胜率63%）** | **华泰金工 2025-08** |

规律：**写的人越专业、更新频率越低，预测力越强**。
新闻是已发生的事（价格已反映，半强有效市场）；研报/调研/基金展望含未反映的专业判断。

**华泰方法的可复现细节**：
- 数据源：公募基金季报"市场展望"章节（约30%基金公布，单季≥367只）
- 两指标：关注度（提及该行业的基金数占比） + 情感得分
- 情感词典：大连理工情感本体库 + 中文金融情感词典(姜富伟等) + GPT/FinBERT 扩充标注
- 选行业：情感得分前10% 且 关注度前40%；**情感得分优先级高于关注度**
- 剔除行业主题基金后效果显著提升（13.47%→16.23%）
- 中金另测得：乐观区间时展望词频变化率Top5行业未来20日胜率89%

**LLM 的正确用法（华泰 LLM-FADT + 国联民生）**：
不是让 LLM 直接预测涨跌，而是让 LLM 从5个维度解读研报——
标题新解 / 行情催化剂 / 言外之意 / 潜在风险 / 收益指引，
再把解读文本喂 FinBERT → XGBoost。可回测、可复现。
国联民生：调研文本因子 RankIC 3.2%、年化ICIR 2.8、胜率80%，
**中小盘(中证500/1000)增量更明显**。

**必须警惕的证伪证据**：
- 方正证券：分析师词频因子 word_fre_indu 2021年前出色，**之后显著回撤**
- 华泰 LLM-FADT 2026年以来超额 -4.7%（长期年化仍25%）
- 所有文本因子都有时效性，会衰减

**落地路径优先级（待实施）**：
1. 研报标题+摘要情感 → 行业聚合（日频，东方财富研报中心可爬，数据现成）
2. 基金季报展望文本（季频，巨潮cninfo，效果最好但一年4次）

## 板块"启动识别"研究 (sector_breakout.py) — 可行方案

**问题**: 预测"下一个是谁"已被证伪, 改问"板块刚启动时能否判断真假" —— 这个可测。

**方法**: 启动事件 = 板块5日涨幅从20名开外冲进前10(加冷却, 每板块每波只算一次)。
408交易日 × 48行业 → 186 个启动事件(每板块3.9次)。

**踩坑记录**:
1. **板块指数不能用"个股中位价格"**(会随成分股切换跳变, 导致未来收益失真到
   全行业平均+13%)。必须用"个股日收益中位数"累乘: `(1+r1.median()).cumprod()`
2. 启动事件必须加冷却期(过去5天最好排名>20), 否则排名边缘抖动会产生
   4017个假事件(每板块84次), 完全不可用
3. **daily_kline 最新日可能只有极少数股票入库**(9/7仅1只)。所有"当前快照"
   必须挑最后一个 M.notna().sum(axis=1)>=30 的完整交易日

**核心结论: 早期识别有效, 但幅度温和; 真正价值在于"避开假启动"**

## 板块「真主线」识别研究 (sector_mainline.py) — 已解决

**问题**: 板块刚涨起来时, 怎么判断它是这轮真正大涨的板块(而非一日游)?

**方法: 事件标注法(相对口径)**
- 观测池: 5日涨幅排名进前15 的 (行业, 日期), 每3日采样降重叠 → **1627 个观测**
- 标签「真主线」: 未来20日超额收益**同期横截面百分位 ≥ 75%**(450个, 27.7%)
- 绝对口径不可用: 这20个月全行业未来20日平均 **-2.39%**, 涨幅≥15%的仅2~3例;
  涨幅≥8%也只有 3.8%。必须用相对口径。

**踩坑记录**:
1. 事件法(排名从20开外冲进前10)样本太少 —— 最多 102 个, 且真大涨仅 2~3 例 → 改用全观测池
2. `DataFrame.nlargest(3, axis=1)` 不支持 axis → 用 `np.sort(a,axis=1)[:,::-1][:,:3]`
3. **Copy-on-Write 陷阱**: `ev.iloc[i][c] = True` 静默失效(不报错但写不进去)!
   必须用 numpy 数组或 `.iat[]`
4. **判别完整交易日要用个股覆盖数** `px.notna().sum(axis=1)`, 不能用板块指数非空数
   (9/7 只有 2 只股票入库, 但板块指数因 cumprod 仍有值, 会被误判为完整日)

**核心结论: 最强判别特征 = 板块内个股涨幅是否整齐**

| 分组(近5日涨幅标准差) | 样本外真主线率 | 样本外超额 |
|---|---|---|
| 最齐(最小30%, <4.17) | **43.1%** | **+1.51%** |
| 不筛选基准 | 29.0% | -0.16% |
| 最不齐(最大30%, >6.63) | **18.0%** | **-1.77%** |

- 单特征 AUC: disp 0.405(反向最强) / zt5 0.424(涨停少更好) / lead 0.443 / money5 0.447
- 三规则叠加(离散小+涨停少+龙头拉动小): 样本外真主线率 41.2%, 超额 +1.32%,
  亏损超5%仅 7%(基准 13%)
- 逻辑回归: 训练AUC 0.635 → 测试AUC 0.565, **保留率仅 48%**(偏过拟合);
  高低分组未来20日差 1.65 个百分点(+0.40% vs -1.25%)
- 系数: zt5 -0.525(涨停多反而差) / disp -0.309 / quiet20 -0.353(前期跌得多反而好)

**与既往结论的一致性(第4条独立证据)**:
