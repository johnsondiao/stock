## 复用要点
- 命令必须前置 no_proxy/NO_PROXY，Python 用 miniconda3 解释器
- **不要对 pm_check.py 用 shell 重定向 `> pm_check.txt`**：脚本内部自己以 utf-8 写该文件，
  重定向会与之冲突导致文件乱码（UTF-8 字节被当 GBK 读）。直接裸跑即可。
  读取同理：必要时用 python 显式 encoding='utf-8' 读。
- HOLD 列表每次先读 weekend_review.py，用户 query 里的持仓可能过时
- 广度阈值 55%：低于即不开仓，不必再挑标的
- 广度与 ma_combo 命中数正相关，可作为交叉验证（70%→18只，37%→4只）
